⚡ Admin execution notes

Elevated launch: open Run with Win + R, enter a command, then use Ctrl + Shift + Enter where supported to request elevation.

Be deliberate: Registry Editor, Disk Management, Services and boot tools can change system behaviour. Inspect before changing settings and keep a recovery path.

Availability: some consoles, including Local Group Policy Editor and Local Users and Groups, are not included in every Windows edition.
